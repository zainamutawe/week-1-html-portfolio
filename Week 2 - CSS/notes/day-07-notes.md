# Day 07 - CSS Box Model

## What I Learned
- The CSS Box Model consists of content, padding, border, and margin.
- Padding controls the space between content and border.
- Margin controls the space outside the border.
- Border defines the element's outline.
- Width controls the element's width.
- Height controls the element's height.
- Border-radius makes the corners rounded.
