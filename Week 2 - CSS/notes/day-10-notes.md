### Day 10 - Media Queries

## What I Learned

* Media Queries allow CSS styles to change based on screen size.
* The @media rule is used to apply styles for different screen widths.
* Responsive design helps make websites usable on mobile, tablet, and desktop screens.
* Different font sizes and layout adjustments can improve readability on smaller screens.

## What I Practiced

* Added a tablet media query using max-width: 768px.
* Added a mobile media query using max-width: 480px.
* Adjusted heading sizes for smaller screens.
* Allowed the navigation links to wrap on smaller screens.
* Changed the card layout to a vertical layout on smaller screens.
* Adjusted the image gallery to display one column on mobile screens.
* Adjusted navigation spacing and input sizing for mobile screens.

# Result :

Applied responsive CSS styles to the existing portfolio pages and layouts to improve their usability on different screen sizes.
