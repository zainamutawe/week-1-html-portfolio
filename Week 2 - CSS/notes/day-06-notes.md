# Day 06 - CSS Selectors and Typography

## What I Learned
- CSS is used to style HTML pages.
- CSS rules consist of selectors and declaration blocks.
- Element selectors target HTML elements such as h1, p, nav, and a.
- Color properties change text and background colors.
- Font-size controls the size of text.
- Font-weight controls how bold the text appears.
- Line-height improves text readability.
- External CSS files can be connected to HTML pages using the link element.
