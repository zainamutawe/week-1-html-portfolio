# Day 01 - Web & Setup
## 1. Browser

what is a Browser? 
A browser is a software application used to access and display websites.

My notes:

* Examples: Google Chrome, Firefox, Microsoft Edge.
* The browser sends requests to servers and displays the received web pages.

## 2. Server

what is a Server? 
A server is a computer or system that provides data or services to other computers (clients).

My notes:

* A server receives requests from clients.
* It processes requests and sends back responses.

## 3. HTTP

what is HTTP?
HTTP stands for Hypertext Transfer Protocol. It is a protocol used for communication between browsers and web servers.

My notes:

• The browser sends an HTTP request.
• The server sends an HTTP response.
• HTTP is used to transfer web page data.
