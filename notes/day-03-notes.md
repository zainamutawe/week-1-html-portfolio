## Day 3 – Lists and Tables

# 1. What I Learned

* Learned how to create tables in HTML using <table>.
* Learned how to create table rows using <tr>.
* Learned how to create table headers using <th>.
* Learned how to add table data using <td>.
* Learned how to create unordered lists using <ul>.
* Learned how to add list items using <li>.
* Learned how to organize trainee information in a directory table.
* Learned how to display skills using separate lists.

# 2. Practical Work

* Created a trainee directory table.
* Added three trainees with their names, ages, and specializations.
* Created separate skills lists for each trainee.
* Used HTML table and list elements.

## 3. Testing

* Test Case 1: Checked that the trainee table displays all three trainees and their information correctly.
* Test Case 2: Checked that all three skills lists display the correct skills.

# 4. Problems and Solutions

* Problem: The table border was not displayed correctly.
