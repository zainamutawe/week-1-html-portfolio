## Day 04 - HTML Forms

# 1. What I Learned

* Learned how to create forms in HTML using <form>.
* Learned how to add labels using <label>.
* Learned how to create text input fields using type="text".
* Learned how to create email input fields using type="email".
* Learned how to create password fields using type="password".
* Learned how to connect labels to input fields using for and id.
* Learned how to make fields required using the required attribute.
* Learned how to create a submit button using <button type="submit">.

# 2. Practical Work

* Created a registration form.
* Added Full Name, Email, and Password fields.
* Added labels for all input fields.
* Made all fields required.
* Added a Register button to submit the form.

# 3. Testing

1. Tested the form with empty fields and confirmed that the browser prevents submission.
2. Tested an invalid email address (abc) and confirmed that the browser displays a validation message.
